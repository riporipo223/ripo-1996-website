i'm just a guy who can't leave an idea alone until it has a repo, a real deployment, and something people can actually open.

i'm currently finishing cryptofolio, my thesis, a crypto portfolio tracker with on-chain wallet reads and a fifo cost-basis engine for figuring out real gains and losses. the manuscript documenting it got rejected the first time out: not enough novelty, one wallet wasn't a real validation set, prototyping alone wasn't seen as research. so i spent weeks closing every one of those gaps: real code fixes, independent manual verification, expanded the validation to six real wallets including vitalik.eth and the ethereum foundation, found bugs along the way that actually mattered: silently truncated pagination, mis-rounded stablecoin amounts, failed transactions counted as real money moving. it's ready for review now.

alongside that i built ilovemusic, open-source music software for collectors, diggers, and developers, a desktop app that pulls tracks from soundcloud, spotify, and bandcamp, reads bpm and key, and embeds the metadata properly. it's shipped for macos. i also run a public api for it off my own machine, and there's a cli sitting on top of that too.

some of this has worked out. some of it is still mid-fight. but i'd rather ship something real and messy than talk about something clean and hypothetical.

still a student. still building.
